# CS420A - Quản Lý Cửa Hàng Đồ Chơi (QuanLyDoChoi)

Dự án Đồ Án Web App Quản Lý Cửa Hàng Đồ Chơi xây dựng bằng **ASP.NET C# (Web Forms .NET Framework 4.7.2)** kết hợp **Bootstrap 5** và **SQL Server Database (ADO.NET / LocalDB)**.

---

## 🚀 Tính Năng Chính
1. **Đăng nhập & Phân quyền Session (3 Roles)**: `Admin`, `BanHang`, `Kho`.
2. **Trang Bán Hàng (POS)**: Tìm kiếm sản phẩm live, giỏ hàng, thanh toán tự động trừ tồn kho trực tiếp và hiển thị Hóa đơn.
3. **Trang Quản Trị Kho**: Xem danh sách tồn kho, thêm sản phẩm đồ chơi mới, cập nhật số lượng nhập kho.
4. **Trang Lịch Sử Hóa Đơn**: Lưu trữ danh sách hóa đơn bán ra và xem chi tiết mặt hàng trong từng hóa đơn.
5. **Dữ liệu SQL Server**: Khởi tạo bảng (`NguoiDung`, `SanPham`, `HoaDon`, `ChiTietHoaDon`) và dữ liệu mẫu khởi tạo sẵn.
